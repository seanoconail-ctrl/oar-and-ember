# tools

Development tools that run in Node: autoplay, scenario runner, reachability, content lint, art compiler, art lint, render-to-image checks and the two-pass browser test runner (`test/browser.ts`).

- **May depend on:** Any layer; the only place Node built-ins are allowed.
- **Built in:** Stage 1 (title render check), then Stages 3, 4, 10, 16 and 20
