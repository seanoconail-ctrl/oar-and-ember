# content

Game content as JSON, validated at load (Book 2 section 04). Every tuning number lives in `balance.json`, generated from Book 10; nothing else holds numbers.

- `balance.json`: the Book 10 tables.
- `ids.json`: the ID registry seeded from Books 4 to 11 (stable forever).
- `strings/en.json`: player-facing text by string key (Book 8 section 10).
